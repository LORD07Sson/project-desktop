# Project Desktop

Программа для команды дубляжа Project. Здесь ваши серии и сроки, тайтлы
сезона, чат команды и просмотр аниме — всё в одном окне.

## Установка

1. Откройте [последний релиз](https://github.com/LORD07Sson/project-desktop/releases/latest).
2. Скачайте `ProjectDesktop-win-Setup.exe` и запустите.

Обновления ставятся сами.

## Вход

1. Напишите боту команды в Telegram `/desktop`.
2. Введите присланный код в программе.

Код действует 5 минут.

## Что умеет

- **Моя очередь** — ваши серии и сроки.
- **Тайтлы** — голосование за аниме сезона.
- **Календарь** — сроки и выход серий.
- **Сообщения** — общий чат и личные переписки.
- **Смотреть** — каталог сезона и плеер.
- **Инструменты** — проверка звука, обрезка и конвертация видео.
