# Смена домена сервера

Адрес сервера (`voice_report_bot/miniapp`) задаётся в каждом репозитории в одном месте:

| Где | Что поменять |
|---|---|
| project-desktop | `npm run set-server -- https://новый.домен[:порт]` — правит `server.json` (его читают интерфейс и Rust при сборке) и CSP в `src-tauri/tauri.conf.json`. `npm test` проверит, что адрес нигде не вписан руками и CSP его пропускает. |
| project-android | `SERVER_ORIGIN` в `gradle.properties`. |
| voice_report_bot | переменная `MINIAPP_URL` в окружении сервиса (`/etc/telegram-bot.env` и юнит `telegram-miniapp`) — от неё же берут адрес бот, кнопка мини-аппа и игры. |
| VPS | конфиг nginx и сертификат Let's Encrypt под новый домен. |

## Порядок, чтобы никто не отвалился

1. Новый домен — DNS на VPS, сертификат (`certbot`), блок в nginx **рядом со старым**: какое-то время работают оба.
2. Поменять адрес во всех трёх репозиториях, выпустить новые версии десктопа и Android, перезапустить бота и сервер.
3. Подождать, пока все обновятся: старые версии программы ходят на старый адрес. Обновления десктопа приходят с GitHub, а не с нашего домена, поэтому обновиться получится и после переезда.
4. Только потом выключить старый домен или оставить его перенаправлением на новый.
