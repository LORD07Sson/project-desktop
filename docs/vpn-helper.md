# VPN помощник (X-UI)

Вкладка «Ещё → VPN помощник», видна только владельцу (OWNER_IDS).

## Кто что делает

| Часть | Где | Что |
|---|---|---|
| Чтение панели | сервер бота, `miniapp/xui_helper.py`, `GET /api/dev/vpn/overview` | inbound'ы (порт, протокол, транспорт, TLS/Reality, SNI), статус Xray. Без UUID, паролей и ключей. Кэш 60 с |
| Сетевые пробы | клиент, `src-tauri/src/vpn_probe.rs` | DNS (система против DoH Cloudflare/Google), TCP-серии, TLS с SNI и без, чтение до 96 КБ для «заморозки» ~16 КБ |
| Выводы и UI | `src/app/vpn-helper.js` | классификация: блок IP, блок порта, DPI по SNI/TLS, подмена DNS, SSL, Reality, потери и джиттер |

Пробы идут с компьютера разработчика, потому что блокировки видны только изнутри его сети.

## Осторожность

- Ручной запуск не чаще раза в 2 минуты, авто-проверка раз в 30–60 минут со случайным сдвигом (выключена по умолчанию).
- Не больше двух соединений одновременно, случайные паузы перед каждым.
- Только порты включённых inbound'ов (до 8) и до 5 доменов. Контрольный хендшейк без SNI — только если с SNI не прошло.
- В пробах нет VPN-протокола. Если на компьютере включён VPN/прокси (connect за ~1 мс), вкладка предупреждает, что результаты отражают туннель.

## Настройка сервера (.env бота)

```
XUI_URL=http://127.0.0.1:<порт>/<webBasePath>
XUI_API_TOKEN=<токен «monitor» из Настройки → Безопасность → API Token>
# для старых версий без токенов: XUI_USERNAME / XUI_PASSWORD
XUI_PUBLIC_HOSTS=<домен>,<IP сервера>
```

В `server.py` после `_require_owner`:

```python
import xui_helper
app.include_router(xui_helper.make_router(_require_owner))
```
