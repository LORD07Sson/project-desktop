# Политика безопасности

## Область

Репозиторий приватный и используется только внутри студии PROJECT.
Ниже — как безопасно сообщить о проблеме и что вообще относится к
поверхности атаки этого клиента.

## Как сообщить об уязвимости

Публично (issue, комментарий) — не сообщайте. Напишите напрямую
владельцу репозитория (LORD07Sson) или ответственному за бота в студии
с описанием:

- что нашли и как воспроизвести;
- версию клиента (`Настройки` → видно внизу, либо файл `VERSION`);
- ОС и способ установки (готовый релиз / сборка из исходников).

Ответ и статус — в течение нескольких дней, срок закрытия зависит от
серьёзности.

## Что считается уязвимостью в этом проекте

- Обход входа по коду (`/api/desktop/pair`) без знания кода из бота
- Возможность прочитать/подделать токен `dsk_...` другого пользователя
- Инъекция через поля отчёта/заметок, которая выполняется в WebView
  клиента (XSS) — фронтенд рендерит данные с сервера напрямую в DOM,
  см. `dist/app.js`, функция `esc()` — если где-то экранирование
  пропущено, это баг безопасности
- Обход подписи автообновления (принятие непровподписанного апдейта)
- Утечка токена из нативного хранилища ОС (`keyring`) в лог/файл/сеть

Не относится к уязвимостям: сама доступность бизнес-функций
администратору студии (модель доверия — все, кто получил код через
`/desktop` в боте, уже являются членами команды).

## Обработка секретов в этом репозитории

- `TAURI_SIGNING_PRIVATE_KEY` / `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` —
  секреты GitHub Actions, используются только в CI для подписи
  автообновлений, нигде не хранятся в коде и не логируются
- Токен десктоп-клиента (`dsk_...`) хранится на диске пользователя
  только в нативном хранилище учётных данных ОС (Credential Manager /
  Keychain / Secret Service), не в открытом файле — см.
  `src-tauri/src/token_store.rs`
- Сервер хранит не сам токен, а его SHA-256-хеш (`database.py`,
  `create_desktop_token`/`resolve_desktop_token`) — компрометация базы
  не раскрывает действующие токены напрямую

## Известные исключения (Dependabot)

- **[GHSA-wrw7-89jp-8q8g](https://github.com/LORD07Sson/project-desktop/security/dependabot/1)**
  (`glib` < 0.20, транзитивно через `gtk`-биндинги трея на Linux) —
  отклонён как приемлемый риск: Tauri сам требует `gtk = "^0.18"`
  (тянет `glib` 0.18.x), фикс возможен только апстрим-обновлением
  Tauri/gtk-rs. Уязвимый путь (`VariantStrIter`) нигде не вызывается
  ни нашим кодом, ни кодом Tauri в этой конфигурации — риск не в
  использовании, а в самом наличии кода в бинарнике.
