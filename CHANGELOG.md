# Changelog

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
Версии — `VERSION`/`src-tauri/tauri.conf.json`, дата — день слияния в `main`.

## [Unreleased]

- Вкладка «Я» — широкая раскладка под окно ПК (карточка человека
  прилипает слева при скролле), ховер-карточка профиля при наведении
  на любой аватар в приложении, контекстное меню по правому клику в
  «Команде», системное уведомление о выполнении цели месяца
- Доска — колесо мыши и drag пустого места теперь скроллят её по
  горизонтали
- Альфа-релиз на GitHub помечается как Pre-release
- `cleanup_caches.yml` — ежедневная чистка просроченных кэшей
  `actions/cache` (их плодит `codeql.yml`)

## [0.5.9] — 2026-09-15

- Альфа-канал обновлений (rolling-релиз `alpha-latest`, переключатель
  в Настройках) + защита от подвисания вкладок и кнопки «Обновить»
- Доска — drag&drop карточек переведён на Pointer Events (нативный
  HTML5 Drag and Drop ненадёжен в реальном WebView2)
- Перетаскивание файла из проводника на открытую карточку отчёта

## [0.5.8] — 2026-09-15

- Доска: цветные колонки + drag&drop карточек между статусами
- Desktop-native UX: боковая навигация вместо вкладок сверху,
  командная палитра (Ctrl+K), быстрые действия по наведению на строку

## [0.5.7] — 2026-09-15

- Довезены недостающие фичи: админ-панель, тайтлы, разбивка по
  пайплайну

## [0.5.6] — 2026-09-15

- 11 недостающих фич из мини-аппа: карточка отчёта, профиль, обзор,
  режим разработчика

## [0.5.5] — 2026-09-15

- Фикс: приложение вечно висело на сплэше — внешний import map не
  грузился в реальном WebView2
- Мелкие фиксы CI (опечатка в закреплённом SHA256 ffmpeg.zip)

## [0.5.0] — 2026-09-15

- Раздроблен `dist/app.js` (~2000 строк) на модули по темам
- Переход на Velopack для автообновления (вместо
  tauri-plugin-updater + NSIS)
- ffmpeg встроен в установщик — не нужно ставить отдельно
- Баннер, доска, тайтлы, команда, режим разработчика

## [0.4.3] — 2026-09-14

- Запрет одновременного запуска двух копий приложения
  (tauri-plugin-single-instance)
- NSIS-установка без прав администратора (currentUser), убран MSI
- Экран загрузки с маскотом, вкладка «Я» в точь-точь как в мини-аппе,
  вкладка «Лента»

## [0.4.2] и ранее — 2026-09-14

- Первые коммиты: Tauri-обёртка вокруг API мини-аппа, базовый список
