## [Unreleased]

### Добавлено

- Заметки с тайм-кодом: у поля заметки появилось отдельное поле времени,
  а само время показывается меткой перед текстом. Когда заметок со
  временем больше одной, их можно переключить в порядок по дорожке —
  получается список правок, а не хронология написания
- Кнопка «QC дорожки» прямо в карточке отчёта: прогоняет локальный QC по
  выбранному файлу и одной кнопкой переносит все находки в заметки
  этого отчёта — каждую со своим временем начала
- `npm test` — общий прогон всех проверок на собранном бандле
  (verify + доска + профиль + заметки), он же теперь гоняется в CI

### Добавлено

- QC звука пакетом: несколько перетащенных (или выбранных в диалоге)
  дорожек считаются по очереди и показываются одной сводной таблицей —
  файл, пик, RMS, находки, — вместо стопки модалок друг поверх друга.
  Клик по строке раскрывает находки, кнопка «сначала проблемные»
  пересортировывает. Один файл по-прежнему открывает подробную карточку
- Вкладка «Я»: кольцо стажа объясняет себя — тир, дни в команде и
  сколько осталось до следующего порога (пороги 30/180/365 теперь один
  список и для свечения кольца, и для полоски)
- Вкладка «Я»: полученные награды показываются чипами, неполученные —
  строкой с остатком и полоской («50+ закрыто — 1 / 50»); раньше
  прогресс лежал в атрибуте title и был виден только под курсором
- Вкладка «Я»: пустые руки вместо «пока нечего показать» предлагают
  свободные серии (сколько их и сколько просрочено) и уводят в «Список»
  с фильтром «без исполнителя»
- Вкладка «Я»: у незаданной цели месяца показывается темп студии за
  месяц, и диалог открывается с этим числом
- `npm run test:profile` — проверка вкладки «Я» и пакетного QC на
  собранном бандле (19 проверок), гоняется в CI

### Изменено

- Рейтинг на профиле прячется, пока в таблице меньше двух человек:
  «#1 из 1» — не достижение, а следствие того, что серии закрывал один
- Прочерк в «Вовремя» объясняет себя: считается по отчётам со сроком

### Исправлено (ревью кода)

- Голосование за тайтл из детальной шторки падало с TypeError и молча
  ничего не делало (`castVote` искал предка `.vote-card`, которого там
  нет)
- Тяжёлые Rust-команды (QC звука, проверка и скачивание обновления)
  выполнялись в главном потоке и морозили окно; из-за этого же
  прогресс-бар обновления не двигался до самого конца скачивания
- Выход из аккаунта не чистил загруженные вкладки и точки отсчёта
  фоновых опросов: следующий вошедший на той же машине видел чужие
  отчёты и получал уведомление «вам назначено N новых отчётов» на весь
  свой список
- «Показать ещё» в Ленте и на Доске вешало второй обработчик на уже
  показанные элементы — клик по ним открывал карточку отчёта дважды
- Диалоги смены статуса/приоритета и выбор роли в dev-панели
  открывались на первом пункте списка вместо текущего значения —
  «Применить», нажатое не глядя, откатывало отчёт в черновик, а роль
  стирало в пустую
- Имя пользователя в шапке появлялось только сразу после ввода кода:
  `/whoami` его не возвращает, теперь оно приходит из `/me`
- Ответ 401/403 больше не сыплется тостами до перезапуска — клиент
  возвращает на экран входа
- Вкладка, упавшая по сети, больше не остаётся с текстом ошибки
  навсегда (пометка «загружено» ставится только после успеха)
- Ошибка на второй странице «Истории»/«Активности» больше не оставляет
  кнопку навсегда нажатой
- Гонка при быстром переключении сезонов в «Тайтлах» (ответ по старому
  сезону затирал новый)
- Ctrl+F больше не перехватывается поверх модалок и на других вкладках;
  Escape в диалоге обновления больше не подвешивает проверку навсегда
- Скачивание вложения отчёта: ссылка `target="_blank"` в webview не
  работала вовсе, а токен уезжал в query-строку — теперь файл тянет
  Rust с токеном в заголовке, путь выбирает нативный диалог
- Двойное экранирование имён на «Обзоре» (`esc()` внутри JSX поверх
  собственного экранирования Solid)
- Текст в интерфейсе снова можно выделить и скопировать
  (`user-select: none` стоял на всём `body`)
- ffmpeg больше не мигает консольным окном на Windows, а результат его
  поиска кэшируется на процесс
- Занятая другим приложением комбинация Ctrl+Shift+P больше не валит
  запуск клиента; трей не паникует при отсутствии иконки
- Переключение канала обновлений сохраняется сразу (`store.save()`), а
  альфа-канал наконец видит свои сборки (GithubSource игнорировал
  pre-release, которыми альфа и публикуется)
- `.aac` перестал быть «неподдерживаемым» при перетаскивании на
  карточку отчёта (списки расширений в QC и загрузке разъехались)

### Изменено

- `upload_report_file` читает с диска только те файлы, которые
  пользователь сам перетащил в окно (плюс лимит размера и проверка
  расширения на стороне Rust)
- Номер версии — один на весь проект: `VERSION` → `__APP_VERSION__`
  (Vite) вместо литерала в `settings.js`, который CI правил sed'ом
- `build.yml` и `build-alpha.yml` публикуют релизы в одной
  concurrency-группе (push с изменением VERSION запускает оба сразу)
- CI гоняет `npm run lint` и `npm run verify`; eslint/jsdom добавлены в
  devDependencies, без них ни то, ни другое не запускалось
- Прод-CSP без `ws://localhost:1420` (для Vite-HMR заведён отдельный
  `devCsp`), `img-src` сужен до своего API
- dependabot следит и за `package.json`
- SECURITY.md описывает реальное положение дел с подписью обновлений
  (её нет) и с токеном в URL картинок

- Фронтенд переведён на Vite (`src/` — исходники, `dist/` — сборка,
  больше не в git); вкладка «Обзор» переписана на SolidJS первым
  примером частичной миграции с vanilla JS — остальные вкладки пока
  без изменений
- Вкладка «Я» — широкая раскладка под окно ПК (карточка человека
  прилипает слева при скролле), ховер-карточка профиля при наведении
  на любой аватар в приложении, контекстное меню по правому клику в
  «Команде», системное уведомление о выполнении цели месяца
- Доска — колесо мыши и drag пустого места теперь скроллят её по
  горизонтали
- Альфа-релиз на GitHub помечается как Pre-release
- `cleanup_caches.yml` — ежедневная чистка просроченных кэшей
  `actions/cache` (их плодит `codeql.yml`)
