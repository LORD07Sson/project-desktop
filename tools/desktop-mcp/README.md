# MCP «глаза» для Project Desktop

Даёт ИИ-агенту (Claude Code) смотреть и пользоваться настоящим окном программы, а не гадать по коду.

## Как включить
**В программе (режим разработчика):** Настройки → «Доступ для ИИ» → включить переключатель → «Перезапустить».
Порт `127.0.0.1:9222` открывается только при включённом переключателе и со следующего запуска.

Или вручную: закройте программу полностью (трей → «Выход») и запустите
`powershell -File scripts\debug-launch.ps1`.

Дальше:
1. В Claude Code сервер `project-desktop` подключается сам по `.mcp.json` в корне репозитория
   (при первом запуске агент спросит разрешение).

## Инструменты
| Инструмент | Что делает |
|---|---|
| `desktop_status` | окна, доступные по порту |
| `desktop_screenshot` | PNG окна |
| `desktop_snapshot` | видимые кнопки/поля с номерами `ref`, координаты и текст страницы |
| `desktop_click` | клик по `ref`, селектору или тексту (двойной/правый) |
| `desktop_type` | ввод в поле |
| `desktop_key` | Enter, Escape, Tab, стрелки, Ctrl+клавиша |
| `desktop_scroll` | прокрутка колёсиком |
| `desktop_eval` | JS в странице для отладки (стили, состояние) |
| `desktop_console` | консоль и необработанные ошибки |
| `desktop_sandbox` | песочница: изменения не уходят на сервер; `role: member/admin/owner` — смотреть глазами роли; журнал перехваченных запросов |
| `desktop_mock` | подменить ответ API: готовый `json` или `transform` настоящего ответа (размножить карточки, длинные названия, пустые списки) |
| `desktop_mock_clear` | убрать моки |
| `desktop_viewport` | эмулировать ширину/высоту окна |
| `desktop_theme` | временно светлая/тёмная тема без сохранения |

## Песочница
Пока она включена, в окне снизу жёлтая плашка «Песочница ИИ». Любой POST/PUT/PATCH/DELETE получает
выдуманный `{ok:true}` и не доходит до сервера — его видно в журнале `desktop_sandbox`. GET-запросы идут
на сервер как обычно, а моки и роль правят ответ уже на этом компьютере. Песочница живёт только в
сеансе агента: отключился агент — программа снова работает с сервером напрямую.

## Безопасность
- Порт доступен только с этого компьютера и только в сеансе, запущенном скриптом; обычный запуск его не открывает.
- Агент работает от вашего имени в уже открытой сессии программы: не оставляйте порт открытым, когда он не нужен.
- Сервер без зависимостей (нужен Node 22+), логинов и паролей не читает и не хранит.
